# Zero-cost stack

| Job | Free tool |
| --- | --- |
| Brain / operator | Grok, Gemini |
| Console | this repo (`index.html`) |
| Hosting | GitHub Pages |
| Documents | Google Docs or Markdown |
| Storefront | Gumroad (free to list) or PayPal.Me |
| Design | Canva free |
| Maps / leads | Google Maps, county business lists |
| Outreach | email you already have, Facebook groups, Nextdoor, LinkedIn |

Upgrade a tool only after a stranger has paid you more than its annual price.
