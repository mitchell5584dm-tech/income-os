# Income OS

Free, offline-first **AI Income Operating System**. Grok or Gemini runs the drafts. You send, invoice, and collect.

No API key. No subscription. Data stays in your browser.

## Launch

```bash
chmod +x launch.sh
./launch.sh
```

Open http://127.0.0.1:8765/ or double-click `index.html`.

- Repo: https://github.com/mitchell5584dm-tech/income-os
- Pages (after first Actions deploy): https://mitchell5584dm-tech.github.io/income-os/

Start with `docs/START_HERE.md` and `docs/LAUNCH.md`.

## How the assistant runs it

1. Fill Setup. Save.
2. Copy the Master System Prompt from Operator.
3. Paste into a dedicated Grok thread or a Gemini Gem.
4. Every morning paste the Daily brief into that same thread.
5. Log deals in Pipeline and cash in Ledger.

Export a backup from Settings before clearing the browser.

## Honesty

This is an operating system, not a payout button. Unsent drafts are not income.
